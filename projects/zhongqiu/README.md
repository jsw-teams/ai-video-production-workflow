# 一个月的月饼

一支 92 秒的纸本水彩与线条动画短片。它从一则哈尔滨家庭的中秋口述出发：邻里合做了一桌月饼；月饼多到节后还进入一个月的早晚餐。影片观察节日劳动如何留下不宏大的“余音”。人物、对白、旁白和画面均为标注过的创作重构，不是原始采访录音或档案影像。

## 文件

- `final.mp4`：完整成片
- `project.yaml`：创作策划、结构、研究区分、声音/动作/镜头与 QA 记录
- `sources.md`：来源和事实核对
- `pipeline.py`：本项目的渲染入口（生成后）
- `assets/`：本地生成的场景、声音及中间素材；不作为仓库素材库

## 观看问题

一顿中秋饭散场后，月饼还会占据接下来一个月的早晚餐。制作、分享和吃不完的余量，是否比“团圆”的抽象说法更能让人记住一个节日？
