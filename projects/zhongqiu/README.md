# 同一个节日，许多种动作

一支约 4 分 30 秒的中秋介绍片。沿用现有历法、月饼证据边界与地方实践研究，讲清中秋如何从历法和秋季进入历史、地方街巷、家庭与现代生活。

制作正在进行。第一道闸门是一支 20–25 秒 POC：连续呈现香港大坑火龙转过街角，再切到家中分月饼；它要同时验证水彩线条一致、人物和物件真实运动、环境转场、同步 Foley、音乐让位和无旁白信息可读性。POC 未通过前不生产整片镜头。

固定成片路径：`final.mp4`。研究、生产素材及 QA 状态见 [project.yaml](project.yaml)，依据与不确定性边界见 [sources.md](sources.md)。本机生产能力记录在仓库根目录 [hardware_report.json](../../hardware_report.json)。
