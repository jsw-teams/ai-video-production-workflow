# 先经过的，是清扫车

一支约 90 秒的观察性短片，取材于新华社 2019 年对环卫机扫司机王立峰的公开人物报道。叙事围绕一个位置变化：平常检查、驾驶清扫车的人，在国庆七十周年庆典那天站到观礼位置，认出庆典队列开始前经过的 11 辆清扫车。

画面是有来源说明的 AI 情境重构，不冒充 2019 年现场影像、录音或本人肖像。叙述者为合成配音，事实范围对应报道中明确记载的行为与个人感受。

## 文件

- `final.mp4`：完整成片
- `project.yaml`：创作策划、案例边界、镜头动作与 QA 记录
- `sources.md`：历史事实和个人报道来源
- `pipeline.py`：本项目的渲染入口（生成后）
- `assets/`：本地生成的场景、声音及中间素材；不作为仓库素材库

## 观看问题

一个平日检查车辆细节的人，第一次从观礼位置看自己的工作，会在万众注视的队列里先看见什么？
